# Sistema di Gestione Candidature IT (ASP.NET MVC)

Applicazione web sviluppata in **C#** con architettura **Model-View-Controller (ASP.NET Core MVC)** in ambiente **Microsoft Visual Studio**. 
Il progetto simula un portale interno per la gestione del processo di selezione del personale tecnico, dalla ricezione del CV fino all'esito dei colloqui.

## Obiettivo del Progetto
Approfondire a livello pratico lo sviluppo enterprise su stack .NET, applicando i principi della programmazione orientata agli oggetti (OOP), la separazione delle responsabilità (pattern MVC) e l'interrogazione di database relazionali.
